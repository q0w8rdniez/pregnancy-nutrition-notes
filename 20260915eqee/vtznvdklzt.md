# 做深圳二代试管婴儿没成功可以三代吗

> 更新时间：2026-09-15 (UTC+8)

有些夫妻在尝试了深圳二代试管婴儿（ICSI，即单精子注射）后没有成功，就会考虑升级到深圳三代试管婴儿（PGT，胚胎植入前遗传学检测）。但问题随之而来：二代试管婴儿失败后是否可以直接转向三代试管婴儿？答案是可以，但需要符合一定条件和医学适应症。

二代试管婴儿失败后能否做三代试管婴儿？

二代试管婴儿失败后，可以尝试三代试管婴儿，但需符合以下情况：

1. 存在胚胎染色体或遗传问题

如果二代试管婴儿失败的主要原因是胚胎质量问题（如胚胎多次发育停滞、反复移植失败），三代试管婴儿可以通过遗传学检测筛选健康胚胎，避免类似问题再次发生。

2. 反复流产或胎停育

如果患者经历过多次流产或胚胎停育，可能与染色体异常有关，三代试管婴儿的遗传学检测能有效降低这种风险。

3. 有家族遗传病史

如果夫妻双方或直系亲属中有遗传病史，三代试管婴儿可以通过基因筛查，避免将遗传病传递给下一代。

4. 高龄女性

女性年龄越大，卵子染色体异常率越高，胚胎发育的成功率会降低。三代试管婴儿能筛选染色体正常的胚胎，提高成功率。

5. 精子问题

男性精子质量较差或存在染色体异常时，ICSI虽然能够完成受精，但无法确保胚胎质量。三代试管婴儿可以检测胚胎的遗传物质，排除染色体问题。

在深圳，试管婴儿技术日益成熟，二代试管婴儿失败后，夫妻可以选择三代试管婴儿，尤其是对于胚胎染色体异常、遗传病、高龄等问题，三代试管婴儿能够提供更优的解决方案。然而，在转向三代试管婴儿前，患者需与医生充分沟通，明确失败原因，评估自身条件和适用性。

通过科学的方案和专业的医疗支持，即使经历失败，患者依然有希望通过三代试管婴儿技术，实现生育健康宝宝的梦想。希望每个家庭都能在深圳先进的试管婴儿技术支持下，早日迎来新生命的降临！
