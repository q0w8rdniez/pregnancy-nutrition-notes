# 耳鼻咽喉头颈外科“爱耳日”宣传通知

> 更新时间：2026-09-11 (UTC+8)

打破时间空间限制，远程获得听力保健

**爱耳日**

关注听力，关爱健康，每年3月3日的“世界爱耳日”，北京朝阳医院耳鼻咽喉头颈外科都会为患者提供健康服务。

**今年特色**

为响应国家“互联网＋医疗健康”模式，在“五个一”方针指导下，对听障人群进行远程助听器调试，特此向社会招募听障患者90人。此次活动由北京朝阳医院和英国南安普顿大学联合发起。

**报名时间**

即日起至3.31日

参与人群：听障（耳聋）患者。

**报名立享优惠**

参与者权益：

1. 免费获得听力学评估

2. 免费远程医疗咨询

3. 免费听力远程助听设备验配

4. 免费调试及听觉康复

**参与者需准备的物品**

1. 自备智能手机1部

2. 自备助听器（无助听器，但愿意参加该活动的患者，项目可提供验配补贴）

3. 需要定期复诊、评估、调试2-4次。

在朝阳医院耳鼻咽喉头颈外科，我们将为您提供安全高效的听力学服务，为了人人都能享有健康的听力，欢迎有需求的人参与。
